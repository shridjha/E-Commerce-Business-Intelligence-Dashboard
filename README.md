# 📊 Olist E-Commerce Business Intelligence Dashboard

An end-to-end Business Intelligence project built using the **Olist Brazilian E-Commerce Dataset** to analyze sales performance, customer behavior, seller performance, logistics, and payment trends using **Excel, SQL, and Power BI**.

---

## 📌 Project Overview

The objective of this project is to transform raw e-commerce data into actionable business insights by leveraging data cleaning, SQL analysis, and interactive dashboards.

The project follows the complete Business Intelligence workflow:

- Data Cleaning using Excel
- Data Analysis using SQL
- Interactive Dashboard Development using Power BI
- Business Recommendations based on analytical findings

---

## 🛠 Tech Stack

- Microsoft Excel
- SQL
- Power BI

## 📂 Dataset

**Dataset:** Olist Brazilian E-Commerce Public Dataset

The dataset contains information on:

- Customers

- Products

# Business Recommendations

Based on the analysis, the following recommendations were identified:

- Optimize logistics in regions with longer delivery times.
- Focus marketing efforts on high-performing product categories.
- Improve customer retention through targeted engagement strategies.
- Monitor customer review trends to identify operational improvement opportunities.
- Analyze payment preferences to improve customer checkout experience.
